# Lead Lifecycle

## Core states

1. `DISCOVERED` — opportunity or lead received.
2. `NORMALIZED` — source, identity and content stored.
3. `DEDUPED` — duplicate check complete.
4. `QUALIFIED` — fit, risk, scope and value assessed.
5. `PROPOSAL_READY` — one selected truthful proposal prepared.
6. `SUBMISSION_PENDING` — waiting for a permitted submission action.
7. `SUBMITTED` — proposal or outreach sent.
8. `REPLIED` — client responded.
9. `NEGOTIATING` — scope, price, deadline or proof discussed.
10. `FUNDED` — payment/milestone or approved payment path confirmed.
11. `HANDED_OFF` — delivery package created.
12. `DELIVERING` — implementation active.
13. `COMPLETED` — accepted by client.
14. `PAID` — payout received.
15. `REVIEWED` — review/testimonial requested or received.
16. `LOST` — not won, with reason.
17. `DISQUALIFIED` — rejected, with reason.
18. `RECOVERY` — technical or communication failure being retried.

## Required fields before proposal

- full original task text
- source and opportunity URL/ID
- client signals available on the platform
- language
- service lane
- estimated work
- risk flags
- proposed case/proof
- proposal version
- proposed price and deadline logic

## Required fields before handoff

- exact scope
- price/payment status
- deadline
- revision boundary
- assets and references
- communication summary
- open assumptions
- next promised action
