# Metrics

## North-star

`NET_FUNDED_REVENUE`

Definition: funded project value attributable to the system, less known platform fees, payment fees, tax estimate and direct delivery costs.

## Funnel metrics

- opportunities discovered
- qualified opportunities
- proposals prepared
- proposals submitted
- first-response rate
- qualified-response rate
- call rate
- funded-project rate
- completion rate
- payout rate
- review rate
- repeat-client rate

## Speed metrics

- alert-to-ingestion time
- ingestion-to-qualification time
- qualification-to-proposal time
- client-message response time
- funded-to-handoff time

## Economic metrics

- average funded value
- median funded value
- estimated delivery hours
- actual delivery hours
- effective net hourly rate
- proposal cost
- AI/API cost
- platform/payment fees
- support/revision load

## Experiment dimensions

- service lane
- platform/channel
- client language
- proposal opening
- proof/case used
- price framing
- deadline framing
- video/demo included
- follow-up strategy

## Decision rule

Do not reallocate service priority based on anecdote. Require a minimum comparable sample and document the decision in `DECISIONS.md`.
