# Freelancehunt Identity, Profile and Verification Sequence

## Purpose

Remove unnecessary local-name blockers while preserving the approved adult-owner model and moving directly toward a publishable profile and paid work.

## Core rule

The genuine adult owner's real identity is required in the live Freelancehunt account, but the owner's name does not need to be duplicated in local project files or sent through chat.

Prepared profile copy should use identity-neutral first-person wording, for example:

> Я — власниця цього профілю та працюю разом із командою Antonov Digital. До виконання проєктів можуть залучатися зазначені в профілі спеціалісти команди. Усі ставки, домовленості, повідомлення, угоди та фінансові операції на Freelancehunt здійснюю особисто.

The public account header provides the owner's actual name.

## Required order

### 1. Adult owner corrects live identity fields manually

Before profile publication or verification, the genuine adult owner personally sets and controls:

- real first and last name
- current real profile photo
- adult-owned phone number
- real date of birth
- Kyiv, Ukraine when accurate
- mailbox and recovery methods

This step does not require Codex to know or store the owner's name.

### 2. Codex publishes ordinary reversible profile fields

After the live profile shows the adult owner's real name and photo, Codex may autonomously apply the prepared:

- Ukrainian, English, Russian and Polish descriptions
- Antonov Digital team disclosure
- Artem Antonov co-founder/partner role
- Vadim developer role
- main and additional specializations
- skills
- availability
- project/milestone pricing presentation
- evidence-ready portfolio cards
- email notification settings

Codex must not change identity, phone, date of birth, documents, payments, verification or legal fields.

### 3. Adult owner completes verification

Only after the live identity fields and core profile are correct, the adult owner personally starts the available verification method and pays the displayed verification fee when required.

Do not pay for or begin verification while the profile still shows another person's name or photo.

### 4. Launch notifications and proposals

After profile publication and verification:

```text
Freelancehunt notification
→ operational Gmail mailbox
→ Railway/Telegram monitor
→ complete opportunity card
→ tailored proposal draft
→ adult-owner submission
```

## Local source policy

- Do not require the adult owner's literal name in `OWNER_INPUT.txt`, profile-copy files or prompts.
- Do not use Artem Antonov as the account owner.
- Do not infer the adult owner's name from a nickname, email alias or photo.
- Use neutral owner wording in prepared public copy.
- The connected browser's live adult-owned profile is the source of truth for identity display.

## Stop conditions

Stop only for:

- live profile still showing another person's identity
- no authenticated adult-owned browser session
- CAPTCHA, OTP/2FA, phone or identity verification
- document upload
- payment, legal acceptance or contract action

A missing local owner-name file is not a blocker for profile copy, categories, skills, portfolio preparation or notification configuration.
